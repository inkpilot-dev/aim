# The A.I.M. browser extension

The extension gives A.I.M. a view into Microsoft Edge and Google Chrome and a way to act in them: list and open tabs, read and snapshot pages, click, type, select, scroll, wait and take screenshots. It is a Manifest V3 extension that connects to the A.I.M. Hub on your own machine over `ws://127.0.0.1:47821/aim/ext`. It sends nothing anywhere else.

## Why it is loaded unpacked

The extension is not distributed through the Edge Add-ons or Chrome Web Store. Both browsers only allow unpacked extensions to be installed by a person using the extensions page; no installer or script can add one silently. The folder must stay where it is after loading, because the browser reads it from disk on every start.

Where the folder is:

| Situation | Folder |
|---|---|
| Installed with `AIM-Setup-<version>.exe` | `%LOCALAPPDATA%\Programs\A.I.M.\resources\extension` |
| Portable executable | `resources\extension` next to the executable's unpacked files (shown in Settings) |
| Source checkout | `packages/extension/dist` (created by `pnpm build:extension`) |
| macOS app bundle | `A.I.M..app/Contents/Resources/extension` |
| Linux AppImage / deb | `resources/extension` inside the application directory |

## Microsoft Edge

1. Open `edge://extensions` (paste it into the address bar).
2. Turn on **Developer mode** in the left pane.
3. Click **Load unpacked** and select the extension folder from the table above.
4. The card "A.I.M. Browser Bridge" appears. Click the puzzle-piece icon in the toolbar and pin A.I.M. so its icon stays visible.
5. On the next browser start Edge shows "Disable developer mode extensions". Choose **Keep** (or close the prompt). Edge may show this each time; it is expected for unpacked extensions.

## Google Chrome

1. Open `chrome://extensions`.
2. Turn on **Developer mode** (top right).
3. Click **Load unpacked** and select the extension folder.
4. Pin the extension from the puzzle-piece menu.
5. Chrome shows a "Disable developer mode extensions" bar at start-up; dismiss it with the cross, not with "Disable".

On Windows, `scripts\install-extension.ps1 -Browser edge|chrome` performs steps 1 and 3's navigation for you: it opens the extensions page and the folder in Explorer and prints the pairing instructions. The **Load unpacked** click itself remains yours.

## Pairing

The Hub accepts an extension connection only when it presents the pairing token generated by A.I.M. on first launch.

1. In the A.I.M. desktop app, open **Settings** and copy the pairing token. Regenerating the token there disconnects every paired browser until they are given the new one.
2. Click the A.I.M. extension icon in the browser toolbar. Paste the token into the pairing field. The port defaults to `47821`; change it only if you changed the Hub port in Settings.
3. The extension shows **Connected** once the handshake succeeds, and A.I.M.'s browser status indicator turns on. If the desktop app is not running, the extension retries every few seconds (backing off to 30 seconds) and connects as soon as it is.

The token is stored in the extension's local storage and never leaves your machine.

## What you will see while A.I.M. browses

### Background tabs

A.I.M. prefers to work in tabs it opened itself and does not need those tabs to be in the foreground. You can keep reading or typing in another tab or another application while it works; your mouse pointer is never moved by browser actions. Only when a task genuinely requires it (for example, confirming a visual layout) will A.I.M. activate a tab, and it tells you when it does.

### The teal cursor

When the tab A.I.M. is working in is the one you are looking at, the content script draws A.I.M.'s own cursor: a teal pointer (`#1ABFB0`) with a white outline, the same mark as the application icon. It glides to the element before a click or a keystroke so you can follow what is happening. The cursor is drawn only while `document.visibilityState` is `visible`; in a background tab nothing is drawn and nothing is wasted. It is an overlay inside the page, not your system pointer, and it never captures your clicks.

### The payment guard

Before dispatching any click, keystroke or navigation, the extension checks the target against A.I.M.'s payment rules: checkout and payment URLs, buttons labelled pay, buy, place order, subscribe and the like, and card, CVC and IBAN fields are all refused, and the attempt is reported back to A.I.M. as a policy block. The Hub performs the same check before the request is sent. See [SECURITY.md](SECURITY.md).

## Permissions requested

The extension is listed in the browser as "A.I.M. Browser Bridge". Its manifest requests `tabs`, `scripting`, `activeTab`, `storage`, `alarms`, `webNavigation` and `clipboardWrite`, with host access to all URLs. Host access is needed to inject the content script that takes accessibility snapshots, draws the teal cursor and performs actions on the pages A.I.M. is asked to work with; `alarms` keeps the service worker's reconnection timer alive; `clipboardWrite` lets A.I.M. place text on the clipboard for you. It does not request `webRequest`, `cookies`, `history` or `downloads`, and it has no remote servers: the only connection it makes is to `127.0.0.1`.

## Updating

After updating A.I.M., open the extensions page and click **Reload** on the A.I.M. card so the browser picks up the new files (or run `install-extension.ps1` again). The pairing token is kept.

## Removing

Click **Remove** on the extension card. If you also uninstall A.I.M., the folder disappears with it; a browser that still lists the extension will show it as corrupted until it is removed.

## Pin the A.I.M. icon to the toolbar

After loading the extension, click the puzzle-piece (Extensions) button in Edge's toolbar, find **A.I.M. Browser Bridge** and click the pin icon next to it. The A.I.M. icon (black square with the teal pointer) then stays in the toolbar; click it at any time to see the connection state or re-pair.

## Seeing A.I.M. work

While A.I.M. acts in a tab, a teal pointer labelled "A.I.M." appears on the page and moves to what it clicks or types into. It shows for every action in that tab, including reading, and fades a few seconds after the last one. It is only drawn in the tab you are looking at, so A.I.M. working in a background tab never puts a second cursor on your screen.

## The "A.I.M." tab group

Tabs A.I.M. opens are collected in a teal tab group named **A.I.M.** in your current window, so its work stays together and out of the way of your own tabs. A.I.M. reuses tabs in that group rather than opening new ones, and tabs it did not open are never moved into it. When A.I.M. works on the page you are on, that tab stays where it is. Collapse the group to hide A.I.M.'s tabs; close the group to close them.

## Extension updates

The extension is versioned with the app. When the app updates itself and the extension running in the browser is older than the one the app carries, A.I.M. asks the extension to reload itself from disk, and a notice confirms the new version. The first update after installing version 0.1.6 or later needs one manual reload (edge://extensions → reload arrow on A.I.M. Browser Bridge); later updates apply automatically. If A.I.M. reports that the extension "is loaded from an old folder", remove it and load it again from the folder shown in Settings → Browser extension.
