# A.I.M. trailer

Source for the 58-second cinematic trailer (1920×1080, 30 fps, 2.39:1 letterbox).

| File | Purpose |
| --- | --- |
| `trailer.html` | The whole film as one deterministic page: `window.seek(t)` draws any moment. Open with `?play` to preview in a browser. |
| `capture.cjs` | Captures the real A.I.M. interface (mock backend, 2×) into `shots/`. Needs the renderer preview server on port 5190. |
| `score.py` | Synthesises the original soundtrack (numpy only) to `out/score.wav`, aligned to the picture's hit points. |
| `render.cjs` | Renders every frame to `frames/` with parallel Chromium pages (Playwright). |
| `stills.cjs` | Renders stills at given times for checking composition: `node stills.cjs 12.5 20.9`. |

Build:

```bash
python3 score.py
node render.cjs
ffmpeg -framerate 30 -i frames/f%05d.png -i out/score.wav -c:v libx264 -preset slow -crf 15 -pix_fmt yuv420p -c:a aac -b:a 256k -shortest -movflags +faststart out/AIM-Trailer.mp4
```

`frames/` and `out/` are not tracked. The music is generated by `score.py`; nothing in the trailer is licensed from a third party. Fonts are Inter and Source Serif 4 (OFL).
